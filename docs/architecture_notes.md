# 系统架构说明

项目围绕“预测 -> 场景 -> 优化 -> 控制 -> 评估”搭建。

## 当前主链路

1. `data` 负责加载样例数据与配置。
2. `forecasting` 给出价格预测或占位预测结果。
3. `scenario` 将预测结果扩展为多场景样本。
4. `optimization` 进行套利、MPC 或 Two-stage 建模。
5. `control` 封装滚动执行逻辑。
6. `evaluation` 输出收益和回测指标。

## 设计原则

- 先打通闭环，再逐步增加市场复杂度。
- 先支持单资产储能，再扩展风光储联合调度。
- 先用统一接口，避免 app 脚本直接依赖底层求解细节。
