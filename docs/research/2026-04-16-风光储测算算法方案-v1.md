# 风光储测算算法方案

## 一、项目背景与目标

本项目旨在为绿电直连场景提供一套风光储容量配置的算法方案。核心目标是在满足负荷需求、绿电使用最低比例、新能源自发自用最低比例等边界条件的前提下，通过优化算法测算出风电、光伏、储能的最佳装机容量配比，以实现系统全生命周期成本（或初始建设成本）最小化。

## 二、适用性说明

本方案只适用于余电上网不考虑上网电价和余电不上网状态，且储能只是作为实现边界条件使用。

测算当地光伏或者风电出力能力，此种模拟只能作为粗评估，不能作为精细化预测。

## 三、核心模块设计

本算法方案主要包含三个核心模块：光伏出力模拟模块、风机出力模拟模块、风光储容量优化配置模块。

### 3.2 算法模块

#### 3.2.1 光伏出力模块

模拟单位容量（1MW）或指定容量的光伏系统在特定气象条件下的出力曲线。

##### 3.2.1.1 pvlib 介绍

无气象数据时会多用到的模型（当前版本暂时不用）：

- `pvlib.location`：地理位置与时间管理，自动获取电站的纬度、经度、时区和海拔等信息
- `pvlib.solarposition`：计算太阳位置
- `pvlib.irradiance`：辐照度建模与转换
- `pvlib.temperature`：组件温度模型
- `pvlib.pvsystem`：光伏系统建模

##### 3.2.1.2 算法设计流程

当前气象数据一般只能拿到 GHI，era5 中可能会有其他指标，建议统一走分离路线。

![光伏算法设计流程](power-market-trading/wind-solar-es1.png)

**1. 参数初始化与缺失值填充**

- 坐标处理：使用 `pvlib.location.Location` 初始化站点
- 默认工程参数：
  - 倾角：若无指定，设定为 `latitude * 0.9`（工程经验值）
  - 方位角：北半球默认 180（正南）
  - 海拔：默认为 0（保守估计）

**2. 物理模型仿真**

- 设备选型：加载典型组件（如 550W 单晶）和逆变器参数
- 辐照度转换：
  - 若气象数据仅有 GHI，使用 `pvlib.irradiance.disc` 模型分离出 DNI 和 DHI
  - 使用 `pvlib.irradiance.get_total_irradiance`（推荐 Hay & Davies 模型）将水平面辐照度转换为斜面辐照度
- 功率计算：调用 `pvlib.pvsystem.pvwatts_dc` 或 ModelChain 计算直流功率，再计算交流功率（考虑逆变器效率、温度损耗、线损等）
- 关键点：此步骤计算的是"单位容量（1MW）"在物理环境下的原始出力曲线

**3. 基于等效小时数的校准**

- 计算原始总量：对原始出力曲线求和，得到 `raw_energy`
- 计算目标总量：`target_energy = 1 (MW) * equiv_hours (h)`
- 计算校准系数：`scale_factor = target_energy / raw_energy`
- 逻辑说明：如果物理模型算出的发电量偏低（例如因为未考虑双面组件增益或实际环境优于气象站），该系数会大于 1，自动修正曲线
- 应用校准：将原始出力曲线乘以 `scale_factor`

**4. 任意容量缩放**

$$\text{final\_output} = \text{calibrated\_unit\_output} \times \text{target\_capacity}$$

##### 3.2.1.3 输入输出建议

**输入：**

![光伏模块输入参数表](power-market-trading/wind-solar-es4.png)

**输出：**

- `output_df`：与气象数据时间索引一致的出力时间序列（单位：MW）

#### 3.2.2 风电出力模块

模拟单位容量（1MW）或指定容量的风电系统在特定气象条件下的出力曲线。

> 注意：风机型号最小应为 1.5MW 容量，所以 1MW 的模拟是以最小型号风机缩放形成的，可能会有一些误差。

##### 3.2.2.1 windpowerlib 介绍

1. **风力涡轮机与风电场建模**：提供 `WindTurbine`、`WindFarm`、`WindTurbineCluster` 等类，可方便地构建从单机到集群的不同规模模型
2. **天气数据的高度校正**：内置对数或线性插值/外推功能，将风速等气象数据校正到风机的轮毂高度
3. **功率输出计算**：通过功率曲线（Power Curve）或功率系数曲线（Cp Curve）计算风力涡轮机的功率输出
4. **尾流损失（Wake Losses）模拟**：提供多种方法考虑上游风机对下游风机的尾流效应，使模拟结果更接近真实情况
5. **功率曲线的平滑处理**：采用专业方法（如 Nørgaard 和 Holttinen 的方法）对功率曲线进行平滑处理

##### 3.2.2.2 算法设计流程

![风电算法设计流程](power-market-trading/wind-solar-es2.png)

**1. 机型自动匹配**

- 情况 A（用户指定了单机容量）：在 windpowerlib 库中遍历所有机型，选择差值最小的机型（最邻近匹配）
- 情况 B（用户未指定）：提取库中所有机型的额定功率，计算中位数，选择最接近该中位数的机型（避免选到极端实验性机型）

**2. 风资源垂直切变（高度外推）**

- 背景：气象数据的风速通常是 10m 或测风塔高度，风机在 `hub_height`（如 100m）运行
- 计算空气密度：利用 `temperature` 和 `pressure` 计算实际空气密度（修正功率曲线）
- 风速外推：使用**对数风切变模型**或**幂律模型**，将气象数据中的风速外推至 `hub_height`

$$v_{hub} = v_{ref} \cdot \left(\frac{h_{hub}}{h_{ref}}\right)^\alpha$$

其中 $\alpha$ 为风切变指数，默认取 0.143（1/7）或根据粗糙度长度计算。

**3. 物理模型仿真**

- 功率曲线插值：将外推后的风速输入到选定机型的功率曲线中，通过插值计算每一时刻的单台风机出力
- 单位化：此时得到的是"单台选定机型"的出力曲线

**4. 基于等效小时数的校准**

- 计算原始总量：`raw_energy_per_turbine`
- 计算目标总量：`target_energy_per_turbine = rated_power * equiv_hours`
- 计算校准系数：`scale_factor = target_energy_per_turbine / raw_energy_per_turbine`
- 逻辑说明：利用"等效小时数"将物理模型的纯理论值修正为符合当地统计规律的实际值（弥补尾流效应、叶片污染、控制策略损失等）

**5. 任意容量缩放**

$$\text{turbine\_count} = \frac{\text{target\_capacity}}{\text{selected\_turbine\_rated\_power}}$$

$$\text{final\_output} = \text{single\_turbine\_calibrated\_output} \times \text{turbine\_count}$$

##### 3.2.2.3 输入输出建议

**输入：**

![风电模块输入参数表](power-market-trading/wind-solar-es5.png)

**输出：**

- `output_df`：最终的风电场出力时间序列（MW）
- `selected_turbine`：最终选用的风机型号

#### 3.2.3 配比规划模型

基于边界条件和成本目标，优化计算风光储的容量配置。

##### 3.2.3.1 算法逻辑

![配比规划模型算法逻辑](power-market-trading/wind-solar-es3.png)

算法的输入分为三类：边界信息、基础数据和参数信息。

**边界信息**

| 参数 | 含义 |
|------|------|
| $P_{load}(t)$ | 负荷曲线（时序数据） |
| $R_{green}$ | 绿电使用最低比例（如全年负荷中至少 80% 由风光提供） |
| $R_{self}$ | 新能源自发自用最低比例（或弃电率上限） |
| $C_{wind}$（可选） | 指定风电容量 |
| $C_{pv}$（可选） | 指定光伏容量 |

**基础数据**

| 参数 | 含义 |
|------|------|
| $I_{wind}(t)$ | 单位风电（1MW）出力曲线 |
| $I_{pv}(t)$ | 单位光伏（1MW）出力曲线 |
| $Price_{wind}$ | 风电单位造价（元/MW） |
| $Price_{pv}$ | 光伏单位造价（元/MW） |
| $Price_E$ | 储能单位能量造价（元/MWh） |

**储能参数信息**

| 参数 | 含义 |
|------|------|
| $C_{rate}$ | 充放电倍率（如 0.5C） |
| $DOD$ | 放电深度 |
| $SOC_{min}$ | 最小荷电状态 |
| $\eta_{in}, \eta_{out}$ | 充放电效率 |

**算法核心逻辑**

算法采用"**外层寻优 + 内层仿真**"的架构：外层负责搜索风光储的容量组合，内层负责根据给定容量组合进行时序生产模拟，校验是否满足边界条件并计算成本。

**变量动态判定机制**

| 情况 | 条件 | 决策变量 |
|------|------|---------|
| A（全规划） | 无指定容量 | $X = [C_{wind}, C_{pv}, E_{ess}]$ |
| B（定光伏） | 指定了 $C_{pv}^{fix}$ | $X = [C_{wind}, E_{ess}]$ |
| C（定风电） | 指定了 $C_{wind}^{fix}$ | $X = [C_{pv}, E_{ess}]$ |
| D（定风光） | 都指定了 | $X = [E_{ess}]$，仅计算最小储能 |

**混合搜索策略**

- **第一阶段（粗搜索）**：在解空间内以较大步长（如 10MW）进行网格扫描，快速找到可行域大致范围
- **第二阶段（精细搜索）**：在粗搜索找到的最优解附近缩小搜索范围，减小步长（如 1MW），精确锁定成本最低点

**内层仿真模型（运行策略）**

- 功率平衡：$P_{gen}(t) = C_{wind} \cdot I_{wind}(t) + C_{pv} \cdot I_{pv}(t)$
- 储能逻辑：
  - 当 $P_{gen} > P_{load}$：优先给储能充电（若不满），剩余部分为弃电
  - 当 $P_{gen} < P_{load}$：优先由储能放电补充（若不空），不足部分为缺电（需购网电）
- 指标计算：
  - 绿电比例 $= \sum P_{used\_green} / \sum P_{load}$
  - 自发自用比例 $= \sum P_{used\_green} / \sum P_{gen}$

**成本目标函数**

$$\min(C_{total}) = C_{wind} \cdot Price_{wind} + C_{pv} \cdot Price_{pv} + E_{ess} \cdot Price_{ess\_E}$$

**算法最终输出**

1. **最优容量配置**：
   - 风电装机容量（MW）
   - 光伏装机容量（MW）
   - 储能容量（MWh）/ 功率（MW）
2. **经济指标**：系统总建设成本（万元）
3. **运行指标**：
   - 实际绿电使用比例（%）
   - 实际新能源自发自用比例（%）
   - 弃电率（%）
