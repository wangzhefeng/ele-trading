## 2. 基本策略

### 2.1 实现思路

1. 蒙西市场规则，参数，申报结算时序确认与配置。
2. 根据合约范围，中长期和实时电价预测情况，历史申报情况，确定中长期、日前、实时申报电量占比。
3. 中长期电量拆解到年度，月度交易量，根据比例逐步建仓，根据电价预测调整。
4. 月度根据持仓量价，给出需要加仓或减仓的期望量价范围，给出集中竞价的量价阶梯曲线。
5. 双边协商、摘挂牌、滚搓，如果能获取实时对手方数据，根据量价范围匹配最优对手单。
6. 日前实时储售联动多目标建模，目标可配置。得到储能计划曲线和日前申报量，日前报量进行风控调整。
7. 根据储能计划曲线评估可调容量。如有需求响应，权衡储能套利与响应收益后输出需求响应申报量。
8. 日内储能滚动优化，目标可配置。包括控需量，调节负荷偏差等。如有需求响应，储能按响应曲线运行。
9. 收益复盘，量价结算与偏差回收，计算预期收益。



### 2.2 策略时序

- 配置项：1
- 中长期：2,3
- 月度：4,5
- 日前：6,7
- 实时滚动：8
- 复盘：9



## 3. 算法框架总体设计

本章在第 1 章接口需求与第 2 章基本策略之上，给出可落地的详细设计。

### 3.1 设计目标

1. 按蒙西时序贯通：**配置 → 中长期建仓 → 月度调整 → 日前储售联动 → 日内滚动 → 日清分复盘**。
2. 同一套量价符号与结算公式贯穿预测、优化、申报、回测，避免口径漂移。
3. 储能与交易解耦又联动：日前先定储能计划再定申报量；日内以储能功率为主控对象，兼顾偏差考核与可选控需。
4. 目标函数可配置权重，支持“套利优先 / 控偏差优先 / 控需优先 / 响应履约优先”切换。

## 4. 数据模型与命名约定

### 4.1 时间粒度

| 场景 | `step` | `N_times` |
| --- | --- | --- |
| 现货交易 / 日清分 | `1/4` h（15 min） | 96 |
| 场站精细调度（可选） | `1/12` h（5 min） | 288 |

统一约定：交易层决策变量均在 15 min 粒度上求解；若接入 5 min 调度，先聚合成 15 min 的 `p_b` / `soc` 边界，再回写细粒度跟踪。

### 4.2 量价符号（贯穿全链路）

与日清分及 `trade_liyang*` 保持一致：

| 符号 | 含义 | 单位 | 日清分列名 |
| --- | --- | --- | --- |
| `Q_long[t]` | 中长期持仓电量 | MWh/刻 | `Q_long` |
| `p_long[t]` | 中长期结算/合约价 | 元/MWh | `p_long` |
| `Q_dayah[t]` | 日前申报（成交）电量 | MWh/刻 | `Q_dayah` |
| `p_dayah[t]` | 日前出清价 | 元/MWh | `p_dayah` |
| `Q_real[t]` | 实时实际用电量（含储能后净负荷） | MWh/刻 | `Q_real` |
| `p_real[t]` | 实时出清价 | 元/MWh | `p_real` |
| `Q_real_pre[t]` | 实时负荷预测（或日前对实时的负荷预估） | MWh/刻 | `Q_real_pre` |
| `p_dayah_pre[t]` | 日前电价预测 | 元/MWh | `p_dayah_pre` |
| `p_real_pre[t]` | 实时电价预测 | 元/MWh | `p_real_pre` |

派生量：

- `Q_dayah_load_pre[t]`：日前负荷预测电量（不含储能）
- `Q_real_load[t]`：实时实际负荷电量（不含储能）
- `Q_dayah_bes_sch[t] = p_b_dayah[t] * step`：日前储能计划电量（放电为正）
- `Q_real_bes_sch[t] = p_b_real[t] * step`：实时储能调度电量
- 净用电：`Q_base = Q_load - Q_bes_sch`，`Q_real = Q_real_load - Q_real_bes_sch`  
  （充电时 `p_b<0`，净用电增加；与参考代码一致）

### 4.3 储能对象 `BES`

```python
BES = {
    'id': 0,
    'p_bcmax': ...,   # 最大充电功率 MW
    'p_bdmax': ...,   # 最大放电功率 MW
    'p_bceff': ...,   # 充电效率
    'p_bdeff': ...,   # 放电效率
    'socmax': ...,
    'socmin': ...,
    'socini': ...,
    'cap': ...,       # 容量 MWh
}
```

决策变量命名：

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `p_bc[t]` | 连续 ≥0 | 充电功率 |
| `p_bd[t]` | 连续 ≥0 | 放电功率 |
| `p_b[t] = p_bd[t] - p_bc[t]` | 派生 | 净放电功率 |
| `soc[t]` | 连续 | 荷电状态轨迹，`soc[0]=socini` |
| `p_g[t]` | 连续 ≥0 | 市电进线功率（调度扩展，控需时使用） |
| `p_xu` | 连续 ≥0 | 需量峰值（调度扩展） |
| `a[t]` | 连续 [0,1] | 光伏消纳系数（有光伏时） |

SOC 递推（注意放电侧除以效率）：

```
soc[t+1] = soc[t]
         + p_bc[t] * step * p_bceff / cap
         - p_bd[t] * step / p_bdeff / cap
```

约束：`socmin ≤ soc[t] ≤ socmax`；净负荷非负  
`Q_load[t] + (p_bc[t] - p_bd[t]) * step ≥ 0`（默认不可倒送）。

日前模型可将功率上界收紧为 `0.8 * p_bcmax/p_bdmax`，为日内留调节裕度。

## 6. 中长期与月度交易（步骤 2–5）

### 6.1 仓位结构

目标持仓结构按预测与风险预算确定三层占比：

```
α_long + α_dayah + α_real = 1
Q_target[t] ≈ Q_load_forecast_long[t]
Q_long[t]   ≈ α_long * Q_target[t]
剩余敞口由月内补购、日前、实时覆盖
```

输入：合约候选、预算、中长期/现货价预测、历史申报与成交。  
输出：建议采购量、配置占比、预计成本、预算占用、需求满足度 → **合约组合配比 / 年度 / 季度 / 月度接口**。

### 6.2 建仓节奏

1. 年度总量 → 分月曲线（负荷形状 × 季节系数）。
2. 月度集中竞价：在目标带 `[Q_low, Q_high]`、价格带 `[P_low, P_high]` 生成分段申报阶梯。
3. 月内：滚搓 / 挂牌 / 双边仅在“持仓缺口 × 价差信号”触发时给出单次建议；无对手盘数据时输出量价走廊，有对手盘时做最优匹配。

### 6.3 持仓缺口再平衡

对每个交易窗口计算：

```
Gap[t] = Q_long_held[t] - Q_need[t]
```

| Gap | 动作 | 优先级 |
| --- | --- | --- |
| Gap ≪ 0 | 补购（竞价/滚搓/挂牌） | 高价差时段优先 |
| Gap ≫ 0 | 减持或转让 | 避免中长期考核 |
| \|Gap\| 小 | 不调整 | 输出不调整原因 |

## 7. 日前储售联动详细设计（步骤 6）

### 7.1 公共输入

- `Q_dayah_load_pre[0:96]`
- `p_dayah_pre`, `p_real_pre`
- `Q_long`, `p_long`（已锁定）
- `BES`, `socini`
- `MarketConfig`

### 7.2 储能日前计划子问题

**变量**：`p_bc[t], p_bd[t], soc[t]`（日前功率上界建议 `0.8*p_b*max`）。

**模式 A — 实时价套利（V1）**

```
min  Σ_t (p_bd[t] - p_bc[t]) * step * (-p_real_pre[t])
```

即鼓励在预测实时电价高时放电、低时充电。

**模式 B — 有效边际电价（V3，推荐）**

考虑申报将落在偏差带边界时的有效购电价：

```
π_eff[t] = lam_u * p_dayah_pre[t] + (1-lam_u)*p_real_pre[t]   if p_real_pre > p_dayah_pre
         = lam_l * p_dayah_pre[t] + (1-lam_l)*p_real_pre[t]   otherwise

min  Σ_t (p_bc[t] - p_bd[t]) * step * π_eff[t]
```

物理含义：储能充放电改变的是净用电，其边际成本应取“日前/实时组合有效价”，而非单一实时价。

**模式 C — 联合优化申报量（V2）**

增加变量 `Q_dayah_opt[t] ≥ 0`，目标：

```
obj_Ecost = Σ_t [ Q_dayah_opt[t]*p_dayah_pre[t]
                + (Q_dayah_load_pre[t] + (p_bc-p_bd)*step - Q_dayah_opt[t]) * p_real_pre[t] ]
obj_pen   = Σ_t Q_aux_dayah[t]   # 偏差超额回收线性化上界
min obj_Ecost + w_pen * obj_pen
```

`Q_aux_dayah` 线性化（与代码一致）：

```
若 p_real_pre > p_dayah_pre:
  Q_aux ≥ (Q_dayah - lam_u * Q_real_t) * (p_real_pre - p_dayah_pre)
若 p_dayah_pre > p_real_pre:
  Q_aux ≥ (lam_l * Q_real_t - Q_dayah) * (p_dayah_pre - p_real_pre)
Q_aux ≥ 0
```

其中 `Q_real_t = Q_dayah_load_pre[t] + (p_bc[t]-p_bd[t])*step`（日前阶段用预测负荷代替真实实时负荷）。

### 7.3 日前申报量生成（风控规则层）

在得到 `Q_dayah_bes_sch = p_b * step` 后：

```
Q_base[t] = Q_dayah_load_pre[t] - Q_dayah_bes_sch[t]

若 p_dayah_pre > p_real_pre + gap:   # 日前偏贵 → 少报，倾向买实时
  Q_dayah[t] = lam_l * Q_base[t]
若 p_dayah_pre < p_real_pre - gap:   # 日前偏便宜 → 多报
  Q_dayah[t] = lam_u * Q_base[t]
否则:
  Q_dayah[t] = Q_base[t]
```

V2 可选融合：若 `Q_dayah_opt[t] > 1`（有效解），用优化量覆盖规则量。  
再经风控裁剪：单点变化率、日总量上下限、与 `Q_long` 的中长期带关系。

### 7.4 日前输出（接口）

**储能日前充放电计划接口**

- `p_bc[96], p_bd[96], p_b[96], soc[97]`
- 预计成本/收益（用 `p_dayah_pre/p_real_pre`）
- 约束提示（SOC 触顶/触底、功率达上限、倒送约束激活）

**日前现货量价申报策略接口**

- `Q_dayah[96]`；价格按市场规则（蒙西若为报量不报价则价格字段置空或填限价）
- 预期成交、风险提示（价差方向错误、偏差带过窄等）

## 8. 日内 / 实时滚动与储能调度（步骤 8）

### 8.1 实时储售模型（`trade_real`）

已知：已出清 `Q_dayah`、`p_dayah`（V3 用实际日前价做考核更贴近实盘）；滚动可见 `p_real_pre`、实际/超短期 `Q_real_load`、当前 `soc`。

**变量**：`p_bc, p_bd`（可用满功率 `p_bcmax/p_bdmax`）。

**目标**：

```
obj_bes = Σ (p_bd - p_bc) * step * (-p_real_pre)     # 套利
obj_pen = Σ Q_aux_dayah                               # 控日前偏差考核
obj_xu  = cxu * max(0, p_xu - P_xu_last)              # 可选控需，来自 sch_v2
min  w_bes*obj_bes + w_pen*obj_pen + w_xu*obj_xu (+ 平滑项)
```

偏差约束同 §7.2，但 `Q_real_t` 改为真实/滚动负荷：  
`Q_real_t = Q_real_load[t] + (p_bc[t]-p_bd[t])*step`。

中长期考核项默认关闭，配置打开时增加 `Q_aux_long`（倍率 `m_long`，价格用加权现货价 `p_jiaquan`）。

### 8.2 滚动优化窗口

- 调度起点可配置（如从 22:00 跨日周期，或从当前刻起未来 H 小时）。
- 每次滚动：固定历史已执行段，优化剩余时段；`socini = soc_last`。
- 输出增量：计划变化 Δ`p_b`、预计收益变化、调整原因（价变 / 负荷变 / SOC 触限 / 控需 / DR）。

### 8.3 调度扩展目标

当场站同时考核需量或峰谷目录电价时，在实时模型中并入：

| 目标项 | 形式 | 作用 |
| --- | --- | --- |
| `obj1` | `Σ p_g[t]*step*cg[t]` | 目录电价电费 |
| `obj4` | `cxu * p_xu_ax` | 新增需量惩罚 |
| `obj5` | 分段 `p_bdmax` 平滑 | 避免尖峰放电 |
| `obj6` | 充电时间加权 | 鼓励提前充电 |

功率平衡：`p_g + a*pv + p_bd - p_bc = load`。

现货储售主路径仍以 §8.1 为准；`obj1/4/5/6` 作为多目标综合运行方案的备选层。

### 8.4 实时充放电调整接口

单点/短时窗口再优化：给定当前 SOC、剩余可调功率、最新 `p_real_pre` 与偏差状态，输出建议功率、持续时间、收益改善、SOC 影响、不可调原因。

## 9. 需求响应（步骤 7）

资源范围：本期**仅储能**。

1. 由日前/滚动计划得到各时段可调容量：
   - 上调（多放电/少充电）：受 `p_bdmax`、SOC、倒送约束限制
   - 下调（多充电/少放电）：对称计算
2. 比较：`ΔR_DR`（响应补偿）vs `ΔR_arb`（放弃套利 + 可能增加的偏差考核）。
3. 若 `ΔR_DR > ΔR_arb + margin` → 参与；输出建议响应电量、时段、履约风险。
4. 中标后：响应时段将 `p_b` 锁定为响应曲线（`DR_FULFILL`），滚动优化在其余时段继续套利/控偏。

对应接口：需求响应参与策略、需求响应资源分配（执行顺序仅储能单资源时退化为时段优先级）。

## 10. 结算、复盘与回测（步骤 9）

### 10.1 结算公式

**量价结算（主口径）**

```
C[t] = Q_long[t]*p_long[t]
     + (Q_dayah[t]-Q_long[t])*p_dayah[t]
     + (Q_real[t]-Q_dayah[t])*p_real[t]
```

**差价结算（校验用）**

```
C2[t] = (Q_long-Q_real)*(p_long-p_dayah)
      + (Q_dayah-Q_real)*(p_dayah-p_real)
      + Q_real*p_long
```

恒等关系应满足 `Σ C ≈ Σ C2`（用于单元测试）。

**日前超额回收**

```
若 Q_dayah > lam_u*Q_real 且 p_dayah < p_real:
  Cpen_dayah = (Q_dayah - lam_u*Q_real)*(p_real - p_dayah)
若 Q_dayah < lam_l*Q_real 且 p_dayah > p_real:
  Cpen_dayah = (lam_l*Q_real - Q_dayah)*(p_dayah - p_real)
否则 0
```

**中长期超额回收（可选）**

```
p_jiaquan = (Q_dayah*p_dayah + Q_real*p_real) / (Q_dayah+Q_real)
Cpen_long = m_long * 类似带状超额项（相对 Q_long 与 Q_real）
```

日汇总：

```
C_daily = Σ_t C[t]
Cpen_daily = Σ_t Cpen_dayah[t] (+ Σ Cpen_long)
Cost_daily = C_daily + Cpen_daily
```

### 10.2 回测流程

```
for day in calendar:
  读取当日 96 点: p_long,Q_long, p_dayah,Q_dayah_hist, p_real,Q_real_hist,
                  p_dayah_pre, p_real_pre, Q_real_pre
  # 决策只用 *_pre 与历史持仓，不用未来出清
  跑 DayAheadCoupledOpt → Q_dayah_strategy, bes_dayah
  跑 IntradayRollingOpt（可用实际 Q_real_load 回放）→ Q_real_strategy, bes_real
  按 §10.1 计算 Cost_strategy
  基准 Cost_baseline = 表内 Cost_daily（或 SCHflag=0 无储能重算）
  记录 ΔCost、Cpen 变化、机会损失时段
```

反事实评估接口输出：

- 相对基准（无储能 / 历史申报 / 规则申报）的机会损失
- 损失时段 Top-K
- 主因：价差预测误差、负荷预测误差、SOC 不足、偏差带触线
- 可改善空间：若完美预知 `p_real/p_dayah` 的上界收益
