## 2. 数据模型与命名约定

### 2.1 时间粒度

| 场景 | `step` | `N_times` |
| --- | --- | --- |
| 现货交易 / 日清分 | `1/4` h（15 min） | 96 |
| 场站精细调度（可选） | `1/12` h（5 min） | 288 |

统一约定：交易层决策变量均在 15 min 粒度上求解；若接入 5 min 调度，先聚合成 15 min 的 `p_b` / `soc` 边界，再回写细粒度跟踪。

**日界约定**：优化窗口统一为**自然日 00:00–24:00 共 96 点**。日内滚动以"当前刻起至当日 24:00"为剩余窗口；如需跨日平滑（如 22:00 起点），由调用方拼接次日 96 点预测并将窗口长度传入，模型本身不内置跨日逻辑（§7.2）。

**结算时段口径**：决策量在 15 min（96 点）粒度求解；**结算与偏差考核时段以市场规则为准**，通行做法为日前/实时按 30 min（48 点）结算、节点电价为该时段内 15 min 电价的加权平均。因此 §5 结算前需将 96 点决策量按结算时段聚合（等权平均或按市场规定的加权），结算时段长度 `settle_periods`（默认 96，即与决策一致）可配置。单元测试需覆盖"96 点决策 → `settle_periods` 点结算"的折算（§14）。

### 2.2 量价符号（贯穿全链路）

本表为全链路**唯一权威**的符号定义；v0 参考的外部原型口径已内联至附录 A 供溯源：

| 符号 | 含义 | 单位 | 日清分列名 |
| --- | --- | --- | --- |
| `Q_long[t]` | 中长期持仓电量 | MWh/刻 | `Q_long` |
| `p_long[t]` | 中长期结算/合约价 | 元/MWh | `p_long` |
| `Q_dayah[t]` | 日前申报（成交）电量 | MWh/刻 | `Q_dayah` |
| `p_dayah[t]` | 日前出清价 | 元/MWh | `p_dayah` |
| `Q_real[t]` | 实时实际用电量（含储能后净负荷） | MWh/刻 | `Q_real` |
| `p_real[t]` | 实时出清价 | 元/MWh | `p_real` |
| `Q_real_pre[t]` | 实时负荷预测（或日前对实时的负荷预估） | MWh/刻 | `Q_real_pre` |
| `p_dayah_pre[t]` | 日前电价预测 | 元/MWh | `p_dayah_pre` |
| `p_real_pre[t]` | 实时电价预测 | 元/MWh | `p_real_pre` |

派生量：

- `Q_dayah_load_pre[t]`：日前负荷预测电量（不含储能，**扣除中长期后的敞口**，见 §8.1）
- `Q_real_load[t]`：实时实际负荷电量（不含储能，**扣除中长期后的敞口**，见 §8.1）
- `Q_dayah_bes_sch[t] = p_b_dayah[t] * step`：日前储能计划电量（放电为正）
- `Q_real_bes_sch[t] = p_b_real[t] * step`：实时储能调度电量
- 净用电：`Q_base = Q_load - Q_bes_sch`，`Q_real = Q_real_load - Q_real_bes_sch`
  （充电时 `p_b<0`，净用电增加）

**符号拼写约定**：`Q_dayah`（日前）为固定拼写，全链路统一；`Q_dayah_opt`（§6.3 模式 C 的优化申报量）保留为独立变量名。`p_da_pre` 等异体拼写禁用，一律 `p_dayah_pre`。

### 2.3 储能对象 `BES`

```python
BES = {
    'id': 0,
    'p_bcmax': ...,   # 最大充电功率 MW
    'p_bdmax': ...,   # 最大放电功率 MW
    'p_bceff': ...,   # 充电效率
    'p_bdeff': ...,   # 放电效率
    'socmax': ...,
    'socmin': ...,
    'socini': ...,
    'cap': ...,       # 容量 MWh
}
```

决策变量命名：

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `p_bc[t]` | 连续 ≥0 | 充电功率 |
| `p_bd[t]` | 连续 ≥0 | 放电功率 |
| `p_b[t] = p_bd[t] - p_bc[t]` | 派生 | 净放电功率 |
| `soc[t]` | 连续 | 荷电状态轨迹，`soc[0]=socini` |
| `p_g[t]` | 连续 ≥0 | 市电进线功率（调度扩展，控需时使用） |
| `p_xu` | 连续 ≥0 | 需量峰值（调度扩展） |
| `a[t]` | 连续 [0,1] | 光伏消纳系数（有光伏时） |

SOC 递推（放电侧除以效率）：

```
soc[t+1] = soc[t]
         + p_bc[t] * step * p_bceff / cap
         - p_bd[t] * step / p_bdeff / cap
```

约束：`socmin ≤ soc[t] ≤ socmax`；净负荷非负
`Q_load[t] + (p_bc[t] - p_bd[t]) * step ≥ 0`（默认不可倒送）。

**独立储能双重身份**：当储能以**独立主体**入市时，按"双重身份"处理——**放电视同发电、充电视同用户**，分别按对应侧价格结算；现阶段多为"报量不报价"优先出清、接受现货价，逐步过渡"报量报价"。用户侧（表后）储能则并入负荷，按净负荷参与。两种主体身份下 `Q_real` 的口径不同，由配置 `bess.market_role ∈ {independent, behind_meter}` 区分；本文默认 `behind_meter`（用户侧，与 §8.1 敞口口径一致），`independent` 为扩展。

**新能源大发/限电时段禁放（可选）**：部分市场规定弃风弃光时段独立储能不得放电。增加可选约束 `bess.no_discharge_on_curtail ∈ {true,false}`（默认 false）：置 true 时，在限电/新能源大发时段集合 `T_curt` 内强制 `p_bd[t]=0, t∈T_curt`。

**循环与退化**：套利目标若只计电价差，会高估收益、放大充放。增加两项可配置退化约束/成本（默认启用成本项、关闭硬上限）：
- 日吞吐上限：`Σ_t (p_bc[t]+p_bd[t])*step ≤ throughput_max_ratio * 2 * cap`（`throughput_max_ratio` 默认 1.0，即日等效满充满放不超过 1 次；置 0 关闭）。
- 线性退化成本：目标中减 `deg_cost_per_mwh * Σ_t (p_bc[t]+p_bd[t])*step`，`deg_cost_per_mwh` 由场站标定（参考仓库 `compute_dispatch_revenue` 的 `degradation_cost` 口径）。

**同时充放电处理**：当 `p_bceff * p_bdeff < 1` 且所有价格非负时，套利型目标的最优解自然不会同时充放电，模型保持 LP。若存在负价（充电赚钱）或惩罚项主导目标，可能出现同时充放电解；此时将配置项 `bess.exclusive_charge_discharge` 置 true，引入 0/1 互斥变量，模型退化为 MILP（求解器选择见 §11.3）。默认 false（LP）。

**终端 SOC 约束**：日前与日内模型均设终端约束 `soc[N] ≥ soc_terminal_min`（默认 `socini`，可配置），防止为套取窗口内价差把电量放空、把缺电成本推给下一窗口。

**跨日 SOC 传递**：前一窗口末端 `soc[N]` 即下一窗口 `socini`，由编排层传递；日内滚动每次重优化时 `socini = soc_last`（当前实测/推算值）。

日前模型可将功率上界收紧为 `0.8 * p_bcmax/p_bdmax`（配置项 `dayahead.power_margin`，默认 0.8），为日内留调节裕度。

#### 3.1.2 `ForecastResult`（预测）

```python
@dataclass(slots=True)
class ForecastResult:
    name: str                    # 对应 §2.2 符号，如 "p_dayah_pre"
```

## 4. 预测输入契约

本章定义**由谁、以什么接口、按什么口径产出**预测量，使预测算法可独立开发、并与优化链路解耦。目标：优化/调度/结算模块只面向 `ForecastProvider` 抽象编程，不关心预测模型内部（统计/ML/外部服务）。

### 4.1 `ForecastProvider` 接口（`forecasting/provider.py`）

```python
class ForecastProvider(Protocol):
    def get_price_forecast(
        self, market: str, horizon: int | str, *, quantiles: bool = False
    ) -> ForecastResult: ...
        # market ∈ {"dayah","real","long"}；horizon 为点数或 "monthly"
        # quantiles=True 时返回分位区间（供 §3.3 策略档"预测价差置信度"切换）

    def get_load_forecast(
        self, scope: str, horizon: int | str, *, quantiles: bool = False
    ) -> ForecastResult: ...
        # scope ∈ {"dayah_open","real_open","long"}
```

**产出原则**：同一 `(market/scope, horizon, issue_time)` 的预测结果唯一确定（幂等），便于回测复现；预测带 `issue_time`（出具时刻），优化模块据此防止使用未来信息（§10 的"只用 `*_pre`"约束由 `issue_time ≤ 决策时刻` 强制）。

**与仓库 `ForecastOutput` 对齐**：`ForecastResult`（§3.1.2）扩展了仓库 `forecasting/base.py` 的 `ForecastOutput`，增加 `issue_time`、`quantile_level`、`freq_minutes`，并支持多分位带。现有 `ForecastOutput` 保持不变，`ForecastResult` 作为其超集（修正 B1）。`ForecastResult` 落位 `trading/contracts.py`，`ForecastProvider` 落位 `forecasting/provider.py`。

### 4.2 预测量清单（消费方 → 产出方）

| 预测量（§2.2） | 含义 | 时域 / 粒度 | 消费模块 | 预测接口方法 |
| --- | --- | --- | --- | --- |
| `p_dayah_pre[t]` | 日前电价预测 | 未来 1 天，96 点 | 日前优化（§6） | `get_price_forecast("dayah", horizon=96)` |
| `p_real_pre[t]` | 实时电价预测 | 未来 1 天或滚动剩余窗口，96 点 | §6、§7 | `get_price_forecast("real", horizon=...)` |
| `Q_dayah_load_pre[t]` | 日前负荷预测（敞口） | 未来 1 天，96 点 | §6.1/§6.4 | `get_load_forecast("dayah_open", horizon=96)` |
| `Q_real_pre[t]` | 实时负荷预测 | 滚动剩余窗口 | §7 | `get_load_forecast("real_open", horizon=...)` |
| `Q_load_forecast_long[t]` | 中长期负荷预测 | 分月 / 年度 | `MidLongPlanner`（§8.1） | `get_load_forecast("long", horizon="monthly")` |
| 中长期价预测 | `[P_low,P_high]` 价格带 | 分月 | §8.2 | `get_price_forecast("long", horizon="monthly")` |

粒度统一 15 min（96 点/天），与 §2.1 决策粒度一致；中长期预测按月聚合。所有预测量须带时间索引，列名与 §2.2 符号一致。`dayah_open`/`real_open` 的 "open" 表示**扣除中长期后的敞口负荷**（§8.1 假设）。

### 4.3 实现分层

- **生产实现**：落到 `src/ele_trading/forecasting/`。`price_forecast.py` 扩展支持 `dayah/real/long` 三个市场；`load_forecast.py`（新建，AR+climatology 模式，参照 `wind_forecast`）；`provider.py`（统一接口，内含 `SimpleForecastProvider` 参考实现）。现有 `SimplePriceForecaster`/`ARIMAForecaster` 作占位与回归基线，生产替换为标定模型，输出形状保持 `ForecastResult` 稳定。
- **回测实现**：`trading/noisy_backcast.py` 用 `sca_price/sca_power` 对历史真实量价加噪生成 `*_pre`，使回测"只用预测、不用未来出清"。噪声标定需使回测预测误差的 MAPE 与生产预测服务实测 MAPE 同量级。

### 4.4 置信区间与策略档联动

`quantiles=True` 返回的分位区间用于两类决策：

1. **§3.3 运行策略档切换**：以"预测价差置信度"为例——当 `p_real_pre` 与 `p_dayah_pre` 的分位区间重叠度高（价差不可靠）时偏向 `PENALTY_GUARD`，反之偏向 `ARBITRAGE`。
2. **风控裁剪（§6.4）**：`gap` 阈值可结合价差分位宽度动态收紧/放宽（本期保留固定 `gap`，动态化为扩展）。

置信区间的覆盖率需按 §4.5 单独校准，不得只看点预测误差。

### 4.5 预测精度与验收

预测模块独立验收，指标分两类：

| 类别 | 指标 | 说明 |
| --- | --- | --- |
| 点预测 | MAE、RMSE、MAPE | 各 `*_pre` 分别统计；电价按日时段分组 |
| 概率预测 | 分位覆盖率、pinball loss | `P90` 区间实际覆盖率应接近 90% |

精度阈值**待定**：首批生产/回测数据跑通后标定（参考：日前电价 MAPE 一般 10%~20%，负荷 MAPE 一般 2%~5%），阈值标定前不阻塞优化链路开发（优化链路用回测加噪预测即可联调）。

## 5. 结算公式与机会损失

### 5.1 量价结算（主口径，`trading/settlement_mengxi.py`）

```python
def compute_settlement_C(q_long, p_long, q_dayah, p_dayah, q_real, p_real):
    """C[t] = Q_long*p_long + (Q_dayah-Q_long)*p_dayah + (Q_real-Q_dayah)*p_real"""
    return q_long * p_long + (q_dayah - q_long) * p_dayah + (q_real - q_dayah) * p_real
```

### 5.2 差价结算（校验用）

```python
def compute_settlement_C2(q_long, p_long, q_dayah, p_dayah, q_real, p_real):
    """C2[t] = (Q_long-Q_real)*(p_long-p_dayah) + (Q_dayah-Q_real)*(p_dayah-p_real) + Q_real*p_long"""
    return (q_long - q_real) * (p_long - p_dayah) + (q_dayah - q_real) * (p_dayah - p_real) + q_real * p_long
```

恒等关系应满足 `Σ C ≈ Σ C2`（单元测试基准 `|ΣC − ΣC2| < 1e-6 * ΣC`，§14）。

### 5.3 偏差考核回收

**日前超额回收（蒙西带状口径）**

```python
def compute_cpen_dayah(q_dayah, p_dayah, q_real, p_real, lam_l, lam_u):
    """带状回收：越带且价差方向有利时触发"""
    # 若 Q_dayah > lam_u*Q_real 且 p_dayah < p_real:
    #   Cpen = (Q_dayah - lam_u*Q_real) * (p_real - p_dayah)
    # 若 Q_dayah < lam_l*Q_real 且 p_dayah > p_real:
    #   Cpen = (lam_l*Q_real - Q_dayah) * (p_dayah - p_real)
    # 否则 0
```

**中长期超额回收**

真实市场的中长期回收按**月度签约比例 / 月度加权均价**执行。月度口径：

```
签约比例        sign_ratio = Q_long_month / Q_real_month
月度加权现货价  p_spot_m  = Σ_t (Q_real[t]*p_real[t]) / Σ_t Q_real[t]
月度加权合约价  p_long_m  = Σ_t (Q_long[t]*p_long[t]) / Σ_t Q_long[t]

若 sign_ratio > lam_u_long 且 p_long_m < p_spot_m:      # 超签且合约占便宜
  Cpen_long = m_long * (Q_long_month - lam_u_long * Q_real_month) * (p_spot_m - p_long_m)
若 sign_ratio < lam_l_long 且 p_long_m > p_spot_m:      # 缺额且买贵
  Cpen_long = m_long * (lam_l_long * Q_real_month - Q_long_month) * (p_long_m - p_spot_m)
否则 0
```

其中 `Q_long_month = Σ_t Q_long[t]`、`Q_real_month = Σ_t Q_real[t]`（按结算月聚合）。触发逻辑与日前带状回收一致：签约比例越出考核带、且价差方向使越带部分"占便宜"时按比例回收。**已确认（2026-07）**：采用该方向结构；回收倍率 `m_long`、考核带 `lam_l_long/lam_u_long` 数值待 §3.5 规则确认后回填。

**储能豁免**：调研显示部分市场新型主体（独立储能）不参与中长期缺额/超额回收。配置 `cpen_long_applies_to_storage ∈ {true,false}`（默认 true）；独立储能场景可置 false 豁免。

### 5.4 日汇总与机会损失

```
C_daily    = Σ_t C[t]
Cpen_daily = Σ_t Cpen_dayah[t] (+ Σ_t Cpen_long[t])
Cost_daily = C_daily + Cpen_daily
```

机会损失口径见 §10.2（反事实评估）。

## 6. 日前储售联动详细设计

### 6.1 公共输入

- `Q_dayah_load_pre[0:96]`（**扣除中长期后的敞口负荷**，见 §8.1 假设）
- `p_dayah_pre`, `p_real_pre`
- `Q_long`, `p_long`（已锁定，仅用于结算与复盘，不进优化目标）
- `BES`, `socini`
- `MarketConfig`

### 6.2 储能日前计划子问题

**变量**：`p_bc[t], p_bd[t], soc[t]`（日前功率上界 `dayahead.power_margin * p_b*max`）。

**模式 A — 实时价套利**

```
min  Σ_t (p_bd[t] - p_bc[t]) * step * (-p_real_pre[t])
```

即鼓励在预测实时电价高时放电、低时充电。不产出申报量（`q_dayah = q_base`）。

**模式 B — 有效边际电价（默认）**

考虑申报将落在偏差带边界时的有效购电价。**边界方向与 §6.4 申报规则一致**：实时偏贵时少报日前（压下界 `lam_l`）、日前偏贵时多报（压上界 `lam_u`）：

```
π_eff[t] = lam_l * p_dayah_pre[t] + (1 - lam_l) * p_real_pre[t]   if p_real_pre[t] > p_dayah_pre[t]
         = lam_u * p_dayah_pre[t] + (1 - lam_u) * p_real_pre[t]   otherwise

min  Σ_t (p_bc[t] - p_bd[t]) * step * π_eff[t]
```

物理含义：当实时价高于日前价时，少报日前（压在 `lam_l` 下界）更划算，此时每多用 1 MWh 净电量的边际成本是"按 `lam_l` 比例走日前价 + 其余走实时价"的加权；反之日前偏贵则多报、压在 `lam_u` 上界。储能充放电改变的是净用电，其边际成本应取该"日前/实时组合有效价"，而非单一实时价。

**模式 C — 联合优化申报量**

增加变量 `Q_dayah_opt[t] ≥ 0`，目标：

```
obj_Ecost = Σ_t [ Q_dayah_opt[t] * p_dayah_pre[t]
                + (Q_dayah_load_pre[t] + (p_bc[t]-p_bd[t])*step - Q_dayah_opt[t]) * p_real_pre[t] ]
obj_pen   = Σ_t Q_aux_dayah[t]
min obj_Ecost + w_pen * obj_pen
```

`Q_aux_dayah` 线性化（偏差超额回收的线性上界）：

```
若 p_real_pre > p_dayah_pre:
  Q_aux ≥ (Q_dayah_opt - lam_u * Q_real_t) * (p_real_pre - p_dayah_pre)
若 p_dayah_pre > p_real_pre:
  Q_aux ≥ (lam_l * Q_real_t - Q_dayah_opt) * (p_dayah_pre - p_real_pre)
Q_aux ≥ 0
```

其中 `Q_real_t = Q_dayah_load_pre[t] + (p_bc[t]-p_bd[t])*step`（日前阶段用预测负荷代替真实实时负荷）。

模式选择：配置项 `dayahead.mode ∈ {A, B, C}`，默认 B（模式 B 在多数价差结构下与 C 接近，且无额外线性化误差）。模式 A 只优化储能计划（申报量退化为 `Q_base`）；模式 B 优化储能计划后经 §6.4 规则生成申报量；模式 C 把申报量纳入优化变量、可与 §6.4 规则融合。

### 6.3 实现（`trading/day_ahead_coupled.py`）

```python
plan = solve_day_ahead_coupled(q_load_pre, p_dayah_pre, p_real_pre, bess, config, mode="B")
# plan.p_bc, plan.p_bd, plan.soc, plan.q_dayah, plan.expected_cost/revenue
```

### 6.4 日前申报量生成（风控规则层）

在得到 `Q_dayah_bes_sch = p_b * step` 后：

```
Q_base[t] = Q_dayah_load_pre[t] - Q_dayah_bes_sch[t]

若 p_dayah_pre > p_real_pre + gap:   # 日前偏贵 → 少报，倾向买实时
  Q_dayah[t] = lam_l^k * Q_base[t]
若 p_dayah_pre < p_real_pre - gap:   # 日前偏便宜 → 多报
  Q_dayah[t] = lam_u^k * Q_base[t]
否则:
  Q_dayah[t] = Q_base[t]
```

模式 C 可选融合：若 `Q_dayah_opt[t]` 为有效解（求解成功且值在物理界内），用优化量覆盖规则量。

**风控裁剪（参数化）**：对规则量/优化量统一施加：

| 规则 | 参数（默认） | 说明 |
| --- | --- | --- |
| 单点变化率限制 | `risk.max_step_ratio`（0.2） | 相邻刻申报量变化 ≤ `max_step_ratio * Q_base[t]` |
| 日总量上下限 | `risk.daily_qty_band`（±15%） | 当日申报总量 ∈ 预测日总电量 × [0.85, 1.15] |
| 中长期带一致 | `risk.long_band_check`（true） | 申报量与 `Q_long` 合计后不越出中长期考核带时告警（不强制） |

### 6.5 日前输出（接口）

**储能日前充放电计划接口**

- `p_bc[96], p_bd[96], p_b[96], soc[97]`
- 预计成本/收益（用 `p_dayah_pre/p_real_pre`）
- 约束提示（SOC 触顶/触底、功率达上限、倒送约束激活）

**日前现货量价申报策略接口**

- `Q_dayah[96]`；价格按市场规则——蒙西若为报量不报价则价格字段置空或填限价（待 §3.5 第 3 条确认）。
- **申报价格限值**：若需报价，申报价须落在市场限价区间 `[price_floor, price_cap]`（可配置；调研参考：蒙西 -50~1500 元/MWh、河南 50~1200 元/MWh、江苏 0~1500 元/MWh，具体以当期市场公告为准，默认 `[0, 1500]`）。分段申报价生成后统一做限值裁剪。
- 预期成交、风险提示（价差方向错误、偏差带过窄、申报价触限等）。

## 7. 日内 / 实时滚动与储能调度

### 7.1 实时储售模型

已知：已出清 `Q_dayah`、`p_dayah`；滚动可见 `p_real_pre`、实际/超短期 `Q_real_load`（**扣除中长期后的敞口**，§8.1）、当前 `soc`。

**变量**：`p_bc, p_bd`（可用满功率 `p_bcmax/p_bdmax`）。

**目标**：

```
obj_bes = Σ (p_bd - p_bc) * step * (-p_real_pre)     # 套利
obj_pen = Σ Q_aux_dayah                               # 控日前偏差考核
obj_xu  = cxu * max(0, p_xu - P_xu_last)              # 可选控需
min  w_bes*obj_bes + w_pen*obj_pen + w_xu*obj_xu (+ 平滑项)
```

偏差约束同 §6.2 模式 C 的 `Q_aux_dayah` 线性化，但 `Q_real_t` 改为真实/滚动负荷：
`Q_real_t = Q_real_load[t] + (p_bc[t]-p_bd[t])*step`。

**平滑项线性化**：相邻时段功率变化 `|p_b[t] - p_b[t-1]|` 不可直接进 LP（PuLP 不支持绝对值/二次项），用辅助变量 `delta_pos[t], delta_neg[t] ≥ 0` 线性化：

```
delta_pos[t] ≥ p_b[t] - p_b[t-1]
delta_neg[t] ≥ p_b[t-1] - p_b[t]
平滑项 = w_smooth * Σ (delta_pos[t] + delta_neg[t])   # w_smooth 默认 0.1
```

中长期考核项默认关闭；配置打开时增加 `Q_aux_long`（倍率 `m_long`，计费基准用**月度加权现货价 `p_spot_m`**，与 §5.3 月度口径一致；日内滚动中以"当前已累积 + 滚动预测"估计月度签约比例与 `p_spot_m`，月末结算后以实际值回算）。

### 7.2 滚动优化窗口

- 窗口：当前刻起至当日 24:00（自然日界，§2.1）；调用方可传入跨日拼接预测实现 22:00 跨日周期。
- 每次滚动：固定历史已执行段，优化剩余时段；`socini = soc_last`。
- 终端约束：`soc[窗口末] ≥ soc_terminal_min`（§2.3）。
- 输出增量：计划变化 Δ`p_b`、预计收益变化、调整原因（价变 / 负荷变 / SOC 触限 / 控需 / DR）。

### 7.3 调度扩展目标

当场站同时考核需量或峰谷目录电价时（待 §3.5 第 6 条确认是否启用），在实时模型中并入：

| 目标项 | 形式 | 作用 |
| --- | --- | --- |
| `obj1` | `Σ p_g[t]*step*cg[t]` | 目录电价电费 |
| `obj4` | `cxu * p_xu` | 新增需量惩罚 |
| `obj5` | 分段 `p_bdmax` 平滑 | 避免尖峰放电 |
| `obj6` | 充电时间加权 | 鼓励提前充电 |

功率平衡：`p_g + a*pv + p_bd - p_bc = load`。

现货储售主路径仍以 §7.1 为准；`obj1/4/5/6` 作为多目标综合运行方案的备选层（多目标综合运行接口本期以"主方案 = §7.1 结果、备选方案 = 并入扩展目标结果"的简化形式实现，不做 Pareto 前沿枚举）。

### 7.4 实时充放电调整接口

单点/短时窗口再优化：给定当前 SOC、剩余可调功率、最新 `p_real_pre` 与偏差状态，输出建议功率、持续时间、收益改善、SOC 影响、不可调原因（契约见 §3.1.4 `IntradayPlan.adjustment`）。

## 8. 中长期与月度交易

### 8.1 仓位结构（`trading/mid_long_planner.py`）

目标持仓结构按预测与风险预算确定三层占比：

```
α_long + α_dayah + α_real = 1
Q_target[t] ≈ Q_load_forecast_long[t]
Q_long[t]   ≈ α_long * Q_target[t]
剩余敞口由月内补购、日前、实时覆盖
```

输入：合约候选、预算、中长期/现货价预测、历史申报与成交。
输出：建议采购量、配置占比、预计成本、预算占用、需求满足度 → **合约组合配比 / 年度 / 季度 / 月度接口**。

**中长期持仓在日前/日内目标中的处理假设**：日前与日内优化的决策对象是**净负荷敞口** `Q_load - Q_long`，即中长期持仓视为已锁定、从其覆盖的负荷中扣除后再进入 §6/§7 的优化。理由：中长期部分的结算价 `p_long` 与申报决策无关，只平移总成本，不改变边际决策。因此 §6.2/§7.1 中的 `Q_dayah_load_pre` 与 `Q_real_load` 应理解为**扣除中长期后的敞口负荷**。若业务上需要把中长期带（`lam_l_long/lam_u_long`）也纳入优化，则打开 §7.1 的 `Q_aux_long` 项；默认关闭。

### 8.2 建仓节奏与集中竞价阶梯（`trading/monthly_trader.py`）

1. 年度总量 → 分月曲线（负荷形状 × 季节系数）。
2. 月度集中竞价：在目标带与价格带上生成分段申报阶梯。
3. 月内：滚搓 / 挂牌 / 双边仅在"持仓缺口 × 价差信号"触发时给出单次建议；无对手盘数据时输出量价走廊，有对手盘时做最优匹配（§12.2）。

**阶梯申报公式**：

输入：当月目标持仓带 `[Q_low, Q_high]`（由 §8.1 的 `Q_long` 月值 ±容忍带 `pos_tol` 得到）、可接受价格带 `[P_low, P_high]`（由中长期价预测 ±风险预算得到）、分段数 `K`（默认 5）。

```
分段电量步长  ΔQ = (Q_high - Q_low) / K
分段价格步长  ΔP = (P_high - P_low) / K

第 i 段（i = 1..K，买入方向）：
  bid_qty[i]   = Q_low + i * ΔQ          # 累计申报量
  bid_price[i] = P_high - (i-1) * ΔP     # 价格随量递增而递减（买方阶梯）

卖出方向（减持）对称：bid_price[i] = P_low + (i-1) * ΔP，价格随量递增而递增。
```

成交可能性估计：无对手盘数据时按历史出清价分布给出各段的边际成交概率 `P_clear(bid_price[i])`（经验 CDF）；有数据时由 §12.1 的成交模拟接口替换。申报顺序按价格优先级降序（买方）/升序（卖方）。申报价统一按 `[price_floor, price_cap]` 裁剪（§6.5）。

输出 → **集中竞价申报策略接口**（契约见 §3.1.7 `BidLadder`）。

### 8.3 持仓缺口再平衡

对每个交易窗口计算：

```
Gap[t] = Q_long_held[t] - Q_need[t]
```

其中 `Q_need[t] = α_long * Q_load_forecast[t]`（§8.1 口径）。

| Gap | 动作 | 优先级 |
| --- | --- | --- |
| Gap ≪ 0 | 补购（竞价/滚搓/挂牌） | 高价差时段优先 |
| Gap ≫ 0 | 减持或转让 | 避免中长期考核 |
| \|Gap\| ≤ pos_tol | 不调整 | 输出不调整原因 |

阈值：`pos_tol` 为缺口容忍带（默认 `0.05 * Q_need`，可配置）。

## 9. 需求响应（`trading/dr_allocator.py`）

资源范围：本期**仅储能**。

1. 由日前/滚动计划得到各时段可调容量：
   - 上调（多放电/少充电）：受 `p_bdmax`、SOC、倒送约束限制
   - 下调（多充电/少放电）：对称计算
2. 比较：`ΔR_DR`（响应补偿）vs `ΔR_arb`（放弃套利 + 可能增加的偏差考核）。
3. 若 `ΔR_DR > ΔR_arb + margin` → 参与；输出建议响应电量、时段、履约风险。
4. 中标后：响应时段将 `p_b` 锁定为响应曲线（`DR_FULFILL`），滚动优化在其余时段继续套利/控偏。

对应接口：需求响应参与策略、需求响应资源分配（执行顺序在单资源储能时退化为时段优先级）。`margin` 为参与门槛（默认 0，可配置）。

**补偿量级与参与方式**：
- 补偿参考量级（调研）：邀约型**削峰**上限约 2~3 元/kWh（2000~3000 元/MWh）、邀约型**填谷**上限约 0.45~1.5 元/kWh（450~1500 元/MWh），实时型按邀约型 1.1~1.5 倍。`ΔR_DR` 按实际中标补偿价计，`margin` 建议不低于"响应时段偏差考核增量 + 退化成本增量"以覆盖隐性成本。
- 参与方式：用户侧储能通常经**负荷聚合商 / 虚拟电厂**聚合参与需求响应，单资源储能的响应分配退化为时段优先级；独立储能可作为独立主体参与。由配置 `dr.aggregation ∈ {aggregator, vpp, independent}` 标注参与通道（仅影响输出文案与履约风险说明，不改优化目标）。

### 10.2 机会损失与反事实评估

反事实评估接口输出：

- 相对基准（无储能 / 历史申报 / 规则申报）的机会损失
- 损失时段 Top-K（`opportunity_loss_topk`，列 `[t, loss, cause]`）
- 主因：价差预测误差、负荷预测误差、SOC 不足、偏差带触线

### 11.3 求解器约定

- 默认 **PuLP + CBC**（LP），对应 `exclusive_charge_discharge=false`。
- 当打开充放互斥（MILP）或引入分段线性非凸项时，切 **Pyomo + SCIP**（`AGENTS.md` 允许 sizing/变体用 SCIP）。

## 附录 A. 设计依据与溯源

本设计的符号体系、目标函数与参数取值，依据 v0 蓝本及其参考的外部原型口径（`trade_liyang*` 日前/实时储售模型、`sch_v2` 用户侧调度、日清分表）整理如下，供溯源与核对。本附录与正文各章共同构成完整实现依据，无需任何仓库外文件。

### A.1 日清分列结构

回测输入表（每日 96 行）应包含列：
`p_long, Q_long, p_dayah, Q_dayah(hist), p_real, Q_real(hist), p_dayah_pre, p_real_pre, Q_real_pre`。
含义见 §2.2 符号表。`Q_dayah(hist)`/`Q_real(hist)` 为历史实际值，仅用于基准计算与回放，不得进入决策。

### A.2 原型目标函数对照

| v0 参考来源 | v1.3 落点 |
| --- | --- |
| `trade_liyang` 日前模型 | §6.2 模式 A/B/C |
| `trade_real` 实时模型 | §7.1 |
| `sch_v2` 控需/目录电价扩展 | §7.3 `obj1/4/5/6` |

### A.3 初始默认参数

即 §3.1.1 `MarketConfig` 默认值；待 §3.5 规则确认后回填。

### A.4 市场口径差异

本设计的现货模型采用**"日前结算 + 偏差考核 + 日前申报"的双偏差市场口径**（源自 v0 原型 `trade_liyang*`）。需注意：据公开调研，**蒙西现行现货为另一套"单结算"口径**——日前仅预出清、不作财务结算（"只有实时价、没有日前价"），用户侧"不报量不报价"作为价格接受者，电费按"全电量实时参考点价 + 中长期差价合约"结算，回收项为**中长期缺额/超额回收**（月度签约比例口径）而非日前偏差考核。

两套口径的差异对照：

| 维度 | 本设计（双偏差口径） | 蒙西现行（单结算口径，调研） |
| --- | --- | --- |
| 日前是否结算 | 是（`p_dayah` 有财务意义） | 否（日前预出清仅作运行计划） |
| 用户侧申报 | 日前申报量 `Q_dayah` | 不报量不报价（价格接受者） |
| 偏差结算 | 日前 vs 实时偏差 + `Cpen_dayah` | 实际 vs 中长期合约偏差，按实时价 |
| 中长期回收 | `Cpen_long`（本设计） | 中长期缺额/超额回收（月度签约比例） |

**结论**：本设计框架按用户拍板保留双偏差口径；若后续确认面向蒙西现行单结算口径，需重构第 6 章（日前申报量生成）、§6.2 模式 B/C 与 §5.3 的 `Cpen_dayah`，保留储能充放电计划与中长期交易线。该差异已在 §3.5 第 3/4 条列为待规则确认项。
