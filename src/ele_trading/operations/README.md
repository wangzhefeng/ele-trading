# operations — 日前运行与日内滚动

## 当前模块

| 模块 | 当前职责 | 成熟度 |
|---|---|---|
| `day_ahead_coupled.py` | 日前 BESS 运行、可选联合场景 CVaR、DR 两次求解和决策追踪 | 可运行基线 |
| `intraday_rolling.py` | 冻结执行前缀、剩余窗口重优化、DR 履约约束和物理裁剪回退 | 可运行基线 |

## 当前耦合

- 两个模块消费共享 `MarketConfig`，并在需要中长期差价时接收注入的 `SettlementEngine`；
- 日前和日内以市场模式注入的结算语义计算合同差价；
- 日前文件组装物理模型、场景风险、DR、求解、结果提取和 trace；
- 日内通过复用日前入口完成剩余窗口优化，可选消费执行偏差收紧，并在求解失败时生成有记录的物理裁剪计划。

operations 仍不是完整市场无关的 `DispatchStrategy`。多资源可由编排器作为独立资源级日前计划产出；其不可行求解返回结构化无计划结果，但资源级日内、计量和结算未接线。执行偏差收紧已作为日内可选输入接线，均仍属于 [v6 V5-9](../../../docs/策略算法框架详细设计-v6.md) 的实施范围。
