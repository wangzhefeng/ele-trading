# wind_pv_es_calc 配置目录说明

本目录是 `src/wind_pv_es_calc/` 历史风光储测算链路的配置预留目录。当前目录下尚未沉淀正式配置文件，现有脚本中的大量参数仍以内联常量、dataclass 默认值或函数参数形式存在。

## 当前状态

- `config/` 目录为空，仅用于承接后续配置治理。
- `ba_eva_optim_version/` 中的独立测算脚本仍以脚本内参数为主。
- `eva_PV_optim_version/` 中的光伏、风电、储能测算脚本也仍保留较多内联参数和历史路径假设。
- 稳定主线配置目前在项目根目录 `configs/`，主要服务 `src/ele_trading/` 核心包。

## 使用边界

新增配置前先明确归属：

- 若配置服务当前主线 `src/ele_trading/`，优先放入根目录 `configs/`。
- 若配置只服务 `src/wind_pv_es_calc/` 历史链路，可放入本目录。
- 不要把本目录作为临时输出目录；测算结果、图表和中间数据应放到对应数据或结果目录。

## 后续配置建议

后续如果继续治理 `wind_pv_es_calc`，建议按主题拆分配置：

| 建议文件 | 用途 |
|----------|------|
| `paths.yaml` | 原始数据、处理后数据、结果输出的相对路径 |
| `pv.yaml` | 光伏模拟参数，如经纬度、倾角、方位角、系统损耗、等效小时数 |
| `wind.yaml` | 风电模拟参数，如轮毂高度、风切变系数、等效小时数、机型假设 |
| `storage.yaml` | 储能容量、功率、SOC、效率、充放电策略和成本参数 |
| `planning.yaml` | 容量搜索范围、步长、约束阈值和投资成本假设 |

配置落地后，需要同步更新读取入口和验证命令，避免脚本继续依赖硬编码本地路径或 notebook 历史状态。
